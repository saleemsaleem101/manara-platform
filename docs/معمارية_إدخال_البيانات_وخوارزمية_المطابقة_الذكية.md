## 📌 1. الرد العلمي على ملاحظة لجنة التحكيم والمناقشة الجامعية

> **نص الملاحظة:**  
> *"كيف يتم إدخال بيانات مثل المهارات وغيرها، وما هي الخوارزمية، ويجب إظهار المميزات الجبارة للمنصة؟"*

### 💡 خلاصة الرد الهندسي المعتمد:
1. **طرق إدخال البيانات (Data Input Methods):**  
   المنصة **لا تتيح للخريج كتابة المهارات بشكل نصي عشوائي حر**، بل تفرض الاختيار من **دليل المهارات المهيكلة المعتمدة (Predefined Skills Taxonomy)** المصنف وفق تخصصات كليات الحاسوب وتقنية المعلومات (مثل: Python, React, DevOps, SQL, Cybersecurity, Flutter).  
   * **الفائدة العلمية:** القضاء التام على تباين المسميات اللغوية والأخطاء الإملائية (مثل: JS vs JavaScript، أو بايثون vs Python)، وتوحيد المعرفات الفريدة (`skill_id`)، مما يوفر مدخلات رياضية قياسية دقيقة لخوارزمية المطابقة.

2. **الميزة الجبارة في الخوارزمية (Killer Features & Multi-Criteria Matching):**  
   النظام **لا يعتمد إطلاقاً على البحث السطحي للكلمات المفتاحية (Keyword Matching)**، بل يستخدم منظومة مطابقة مركبة وفريدة:
   * **معامل تشابه جاكارد الموزون (Weighted Jaccard Similarity):**  
     $$S_s = \frac{\sum_{s \in G \cap R} w_s \cdot \text{level\_factor}}{\sum_{s \in R} w_s + \sum_{s \in G \setminus R} w_{extra}}$$
     مدمجاً بمستويات الإتقان الأربعة (`BEGINNER`, `INTERMEDIATE`, `ADVANCED`, `EXPERT`) ونسبة استيفاء المهارات الإلزامية.
   * **مصفوفة الأوزان القابلة للتخصيص الكامل من قِبل الشركة:**  
     تتيح المنشأة تحديد ثقل كل معيار بحرية بحيث يكون المجموع = 100%:
     $$\text{Final Score} = w_s \cdot S_s + w_m \cdot S_m + w_e \cdot S_e + w_q \cdot S_q$$
   * **معيار الثقة والتعويض التلقائي لحديثي التخرج (GitHub & Capstone Projects Trust Metric):**  
     المعضلة الكبرى لخريجي كليات الحاسوب الجدد هي اشتراط الشركات لسنوات الخبرة ($S_e = 0$). ابتكرت منصة «منارة» خوارزمية تعويض تفحص تلقائياً:
     1. وجود **مشروع تخرج تطبيقي متخصص** (وزن تعويضي يصل إلى 40%).
     2. وجود **كود حقيقي موثق في مستودعات GitHub** (وزن تعويضي 30%).
     3. وجود **مشاريع برمجية ومحفظة أعمال** (وزن تعويضي 20%).
     4. وجود **فيديو تعريفي موثق (Video CV)** (وزن تعويضي 10%).  
     فإذا كان الخريج حديث تخرج بدون خبرة عملية، تقوم الخوارزمية تلقائياً بحساب درجة جاهزيته البرمجية وتعويض معيار الخبرة لتعكس كفاءته الحقيقية أمام الشركات!

## 🧮 3. الرياضيات التفصيلية لخوارزمية المطابقة الموزونة

### 1) معامل تشابه المهارات (Skills Similarity $S_s$):
يعتمد على نسبة تقاطع مهارات الخريج ($G$) مع مهارات الوظيفة ($R$) مقسوماً على اتحادهما:
$$J(G, R) = \frac{|G \cap R|}{|G \cup R|}$$

ومع إدخال مستويات الإتقان ($L_G$ للخريج، و $L_R$ للوظيفة):
$$\text{level\_factor} = \min\left(\frac{\text{Rank}(L_G)}{\text{Rank}(L_R)}, 1.0\right)$$
حيث الرتب: مبتدئ = 1، متوسط = 2، متقدم = 3، خبير = 4.

### 2) مطابقة التخصص الأكاديمي ($S_m$):
تطابق التخصص الجامعي للقسم مع الشاغر الوظيفي (تطابق علائقي مع جدول `Major`):
$$S_m = \begin{cases} 1.0 & \text{إذا تطابق التخصص تماماً} \\ 0.0 & \text{في حال عدم التطابق} \end{cases}$$

### 3) مطابقة الخبرة مع التعويض الذكي للمشاريع ($S_e$):
إذا كان لدى الخريج سنوات خبرة فعلية ($E_G$) مقارنة بسنوات الخبرة المطلوبة ($E_R$):
$$S_{e\_raw} = \min\left(\frac{E_G}{E_R}, 1.0\right)$$

**خوارزمية التعويض الذكي (The Killer Compensation Algorithm):**
$$\text{Project\_Capability} = 0.40(\text{Grad\_Project}) + 0.30(\text{GitHub\_Repo}) + 0.20(\text{Projects\_Count}) + 0.10(\text{Video\_CV})$$

فإذا كان الخريج حديث التخرج ($E_G = 0$):
$$S_e = \text{Project\_Capability}$$
وبذلك لا يُظلم خريج الحاسوب المتميز برمجياً لمجرد أنه تخرج حديثاً!

### 4) مطابقة المؤهل العلمي ($S_q$):
مقارنة الدرجة العلمية (دبلوم = 1، بكالوريوس = 2، ماجستير = 3، دكتوراه = 4):
$$S_q = \min\left(\frac{\text{Degree}_G}{\text{Degree}_R}, 1.0\right)$$

## 💻 4. مقتطف الكود المصدري المعتمد (من ملف `matching/services.py`)

```python
# 1. معامل تشابه جاكارد
@staticmethod
def jaccard_similarity(set_a, set_b):
    s_a, s_b = set(set_a), set(set_b)
    union = s_a.union(s_b)
    return len(s_a.intersection(s_b)) / len(union) if union else 1.0

# 2. خوارزمية تعويض غياب سنوات الخبرة عبر GitHub ومشاريع التخرج
project_capability = 0.0
if has_grad_project:
    project_capability += 0.40  # مشروع التخرج العملي
if has_github:
    project_capability += 0.30  # كود حقيقي موثق على GitHub
if project_count >= 1:
    project_capability += min(project_count * 0.10, 0.20)  # أعمال إضافية
if has_video:
    project_capability += 0.10  # فيديو تعريفي مهني

# تعويض معيار الخبرة
if grad_exp == 0.0 and project_capability > 0:
    experience_score = round(project_capability, 4)

# 3. احتساب الدرجة النهائية بالأوزان المخصصة للشركة
final_score = (
    (skills_score * job.skills_weight) +
    (spec_score * job.specialization_weight) +
    (exp_score * job.experience_weight) +
    (qual_score * job.qualification_weight)
)
```

   * أشر إلى القائمة المنسدلة وبيّن للجنة أن الخريج **لا يكتب نصاً حراً**، بل يختار من **دليل المهارات المهيكلة (Taxonomy)**، وأشر إلى الشعار التوضيحي الموجود في الصفحة.
2. **الخطوة الثانية (استعراض ضبط الأوزان للشركة):**  
   * سجل دخول كشركة وافتح `/company/jobs/new`.
   * أشر إلى لوحة **أوزان معايير التوافق** وأظهر كيف تستطيع الشركة تحريك الأشرطة (أو اختيار نمط خريجي الحاسوب الجدد) لتحديد ثقل المهارات والخبرة والتخصص.
3. **الخطوة الثالثة (استعراض معيار الثقة وتحليل GitHub):**  
   * افتح لوحة فرز المتقدمين `/company/jobs/1/applicants` أو بطاقة تفصيل التوافق في صفحة `/applications`.
   * أظهر بطاقة **معامل Jaccard** وشارة **معيار الثقة وتعويض سنوات الخبرة عبر مشاريع التخرج وروابط مستودعات GitHub**.
