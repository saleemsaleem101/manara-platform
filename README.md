## 🛠️ التقنيات المستخدمة (Tech Stack)
- **الواجهة الأمامية (Frontend):** React 18, TypeScript, Tailwind CSS, Vite, React Router DOM.
- **الواجهة الخلفية (Backend):** Python 3.13, Django 5.0, Django REST Framework, Django CORS Headers, Token Authentication.
- **قاعدة البيانات (Database):** PostgreSQL 18 (`manarah_db1`).
- **إدارة المشروع وضمان الجودة:** Jira Software, Agile / Scrum Methodology.

## 🚀 دليل تشغيل المشروع محلياً

### 1. تشغيل الواجهة الخلفية (Django Backend):
```bash
# 1. الانتقال لمجلد الباك إند
cd manara-backend

# 2. تفعيل البيئة الافتراضية
.\venv\Scripts\activate

# 3. التأكد من ملف .env وتطبيق الهجرات الأولية على manarah_db1
python manage.py migrate

# 4. بذر البيانات التجريبية لحسابات الخريجين (اختياري وسريع للمناقشة)
python manage.py seed_sprint1

# 5. تشغيل خادم التطوير
python manage.py runserver 8000
```
> الواجهة الخلفية تعمل على: `http://127.0.0.1:8000/`

### 2. تشغيل الواجهة الأمامية (React Frontend):
```bash
# 1. الانتقال لمجلد الفرونت إند
cd Manarah-Frontend

# 2. تثبيت الحزم (إن لم تكن مثبتة)
npm install

# 3. تشغيل خادم التطوير
npm run dev
```
> الواجهة الأمامية تعمل على: `http://localhost:5173/`

## 🔗 نقاط النهاية الأساسية للـ API (Sprint 1 Endpoints):
- `POST /api/auth/register/` - إنشاء حساب خريج جديد بالاسم الرباعي.
- `POST /api/auth/login/` - تسجيل الدخول وإصدار التوكن.
- `POST /api/auth/logout/` - تسجيل الخروج وإبطال التوكن.
- `POST /api/auth/verify-email/` - تأكيد البريد الإلكتروني الرقمي (OTP).
- `POST /api/auth/resend-otp/` - إعادة إرسال رمز التحقق (OTP).
- `POST /api/auth/password-reset/` - طلب رابط استعادة كلمة المرور عبر البريد.
- `POST /api/auth/password-reset-confirm/` - تأكيد تعيين كلمة المرور الجديدة.
- `GET /api/profiles/graduate/me/` - استرجاع بيانات الملف المهني الأساسي للخريج المسجّل.
- `PUT /api/profiles/graduate/me/` - تحديث وحفظ البيانات الأساسية للخريج.
